# Coding 20-turn real run — 2026-11-03

Same check as the companion run, but with tools, a 16k window and a real
workspace.

## Setup

- Profile: `variants/coding/profile.deepseek.session.toml`; tools are
  `read_file`, `write_file`, `list_dir` and `code_search`; no shell.
- `context_window = 16384`, `budget_tokens = 12288`, output reserve 4096.
- Temporary workspace with `calc.py` (add, subtract, multiply, divide) and a
  small `README.md`.
- 20 Chinese tasks: add functions, fix the zero-divisor behaviour, rename
  parameters, add type hints, docstrings, tests, a README section and search
  for TODOs.
- Raw capture: `evals/reports/runs/coding-20-turn.log` (gitignored).

## Result

- **20/20 turns reached `Done`**; no `ContextOverflow`, wrap-up, cancellation
  or permission loop.
- 271,631 input tokens and 20,617 output tokens, about 292k total. This is a
  large run and close to the suite's 300k cap; a future session check should
  use fewer turns or smaller tasks.
- After the first call the calibrated budget dropped from 12,288 to about
  11,000, because the four tool schemas, the control tool and the provider
  template cost about 1,300 tokens that the estimate cannot see.
- History by the last turns: 1-2 verbatim turns, no digests, 10-12 segment
  records. Records covered older work; the newest exchange stayed verbatim.

## Workspace verification

- `add` now takes `left` and `right`; `subtract` has type hints; `multiply`
  and `divide` have docstrings; `divide` raises `ValueError` on zero.
- `pow2`, `is_even` (bit operation) and `clamp` (inclusive bounds, documented)
  were added.
- `README.md` gained a function table, notes, examples and usage snippets that
  match the final code.
- The model wrote `test_calc.py` and `conftest.py`. Run externally, the tests
  pass 15/15 with pytest. The agent could not run them itself because the
  profile has no shell.

## Friction found

`write_file` could not create `tests/test_calc.py` because the `tests/`
directory did not exist: `error not_found (os error 3)`. The model fell back to
root-level files and said so explicitly in its answer. This is a real tool
usability gap, not a kernel bug. `write_file` now creates missing parent
directories inside the workspace, with a test.

## Limits

- One provider, one small project, no shell execution and no acceptance plan.
- The model could not run tests; correctness here was checked by us afterwards.
- At 292k tokens this is not a cheap regression; use the synthetic matrix for
  routine checks and reserve real sessions for milestone verification.
