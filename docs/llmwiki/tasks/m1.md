## M1 decisions

- Profiles are parsed as a minimal TOML subset; full schema validation lands in M2.
- `evals/` is deferred until it has real cases (no empty directories).
- FSM transition table covers the declared states; M1 only drives the mock path.
- Persona text is loaded from `[persona] system`, relative to the profile file.
- Verification modes other than `none` return `Unsupported` until M2/M5.
- Tool schemas are typed in `keel-core`; the model adapter renders JSON Schema
  at the wire boundary in M2.
- `cargo-deny` is not installed in the environment; run it once available.
